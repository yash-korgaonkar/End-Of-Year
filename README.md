# Echoes of the Forgotten

A first-person horror escape game built in Unity. Explore a locked facility, solve keypad and door puzzles to move between rooms, and avoid patrolling enemies on the way out.

## Features

- First-person movement and mouse look
- Enemy patrol AI with collision-based fail states
- Keypad puzzles, sliding doors, and room-to-room teleport triggers
- Room-based enemy spawning
- Menus, end screen, sound design, and animated timeline sequences

## Built with

Unity · C#

Open `Echoes-of-the-Forgotten/` in Unity Hub and run the start scene.
